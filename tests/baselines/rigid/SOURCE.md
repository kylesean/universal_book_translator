# rigid (overlay-engine plan golden)

Synthetic baseline for the `rigid` (in-place overlay) PDF render path.

- File: `plan.golden.json` — pinned layout plan (per-block font size + line
  breaks) for a deterministic two-paragraph source page.
- Source: **fully synthetic, generated by the test itself** — no external
  corpus. `tests/unit/test_rigid_overlay_golden.py` typesets a tiny source PDF
  with Typst from a fixed inline `SOURCE_TYP` string (Liberation Serif,
  420×320pt page), derives paragraph blocks from the extracted lines, runs the
  overlay typesetter, and pins both the invariants (no block silently dropped)
  and the resulting plan.
- Why this baseline: the offline book baselines only cover the reflow
  (Markdown/EPUB) path; this is the golden for the overlay/`rigid` engine, so a
  layout change becomes a reviewable diff instead of a silent regression.
- Provenance note: this directory was added when the engine was still named
  `anchored`; it was renamed to `rigid` in `126c714`. The plan golden is
  regenerated with `UBT_UPDATE_GOLDENS=1` — read the diff before committing.
