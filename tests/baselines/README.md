# tests/baselines/ — golden corpora provenance & contract

Every corpus directory here has a provenance note (origin, why it is in the
set, and what it exercises). This file consolidates the former per-directory
`SOURCE.md` notes (merged here in the 2026-09-26 doc cleanup). The baseline
**contract** — what each tier asserts and how goldens are regenerated — lives in
[`docs/design/golden-set.md`](../../docs/design/golden-set.md).

## standard-alice
- File: `standard-alice.epub`
- Source: Standard Ebooks edition of *Alice's Adventures in Wonderland*.
- Why: stable EPUB structure, chaptered prose, recurring entities, and many
  illustrations — exercises ingest, chunking, translation, entity/glossary
  consistency, and every final-format emitter.
- The pre-UBT "skill" pipeline record (38-chunk run, glossary/entity tables,
  per-format byte sizes) and its `scripts/convert.py` / `scripts/merge_and_build.py`
  instructions were removed in the 2026-09-17 doc cleanup; those scripts no
  longer exist. The historical record remains in git history.

## call-of-the-wild
- File: `call_of_the_wild.epub`
- Source: Project Gutenberg eBook #215, *The Call of the Wild* by Jack London
  (d. 1916); public domain, retrieved 2026-09-19 from
  `https://www.gutenberg.org/ebooks/215.epub.noimages`.
- Why: long-form narrative with chapter progression, recurring named entities,
  and continuous flow — replacing the retired animal-farm fixture whose claimed
  Gutenberg provenance was false (Orwell is still under copyright).
- Exercises: streaming chapter cursor + non-destructive checkpointing;
  cross-chapter entity consistency via the Translation Bible; low resident
  memory during sustained execution.

## cognitive-psychology-ch03
- File: `cognitive_psychology_ch03.md`
- Source: Based on Sternberg & Sternberg *Cognitive Psychology*, Chapter 3 structure.
- Why: multi-column textbook typography, isolated sidebars, academic tables,
  mathematics, executable Python code blocks, and academic citations.
- Exercises: 4-layer flow-pollution defense (sidebars must never contaminate
  the `main_story` neighbor context); code/math masking (`skip_translate=1`,
  byte-preserved); scientific terminology consistency; table column preservation.

## dual-column-paper
- File: `dual_column_paper.md`
- Source: Synthetic benchmark modelled on top-tier arXiv NLP/ML publications.
- Why: fixed-layout scientific prose, LaTeX inline/display math, Python
  algorithm implementations, and academic evaluation tables.
- Exercises: math preservation, code-block integrity, table formatting.

## rigid (overlay-engine plan golden)
- File: `plan.golden.json` — pinned layout plan (per-block font size + line
  breaks) for a deterministic two-paragraph source page.
- Source: **fully synthetic, generated by the test itself**;
  `tests/unit/test_rigid_overlay_golden.py` typesets a tiny source PDF with Typst
  from a fixed inline `SOURCE_TYP` string, derives paragraph blocks, runs the
  overlay typesetter, and pins both the invariants (no block silently dropped)
  and the resulting plan.
- Why: the offline book baselines only cover the reflow path; this is the golden
  for the overlay/`rigid` engine, so a layout change becomes a reviewable diff
  instead of a silent regression.
- Provenance: added while the engine was still named `anchored`; renamed to
  `rigid` in `126c714`. Regenerate with `UBT_UPDATE_GOLDENS=1` and read the diff.
